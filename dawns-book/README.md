# 🦢 Dawn's Book

A keepsake baby book and daily Bible companion for Michaela and baby Dawn Bronkhorst, made like a stitched
journal with coloured index tabs.

## Get it as an app (phone or computer)
Dawn's Book is an installable web app, like Book Nook and Abide. It gets its own teddy-bear icon, opens in its own
window and works without internet. Once GitHub Pages is deployed it lives at:

**https://mariastellavanrooyen-blip.github.io/FLY_API_TOKEN/dawns-book/**

To put the latest version online, merge this branch into the repo's default branch. Then on GitHub go to
**Actions → "Deploy frontend + Book Nook + Tend + Abide + Dawn's Book to GitHub Pages" → Run workflow**.

Then on her phone:
- **iPhone (Safari):** open the link, tap Share (□↑) → **Add to Home Screen**
- **Android (Chrome):** open the link, tap ⋮ → **Install app** or **Add to Home screen**

The **Our Details** tab inside the app shows the same steps.

## What's inside (the tabs)
1. **Our Book**: greeting, the swan cover with the countdown to 24 December 2026, today's verse and quick buttons
2. **Photo Album**: cloud chapters from Pregnancy to Month 18–24, each a page with 5 photo slots on its own artwork,
   plus as many extra photos as she likes. Every photo has a caption, date and a note on the back
3. **Mommy & Me**: About Mommy, About Dawn (newborn to 1 year), little firsts, feelings diary, and the family tree
   with aunties, uncles and godparents
4. **Letters**: letters to Dawn, sealed until a date if she wants
5. **Daily Word**: verses for Mama and for Dawn (KJV), today's rhythm with a streak, encouragement, saved verses and a
   memorise helper, all on the puzzle artwork
6. **Prayer Journal**: prayers, answered prayers, God moments and study notes
7. **Our Details**: names, due date, birthday, backup and restore

## Her privacy and her data
Everything is saved on her phone as she types, photos included. Nothing is uploaded anywhere.
Use **Our Details → Download backup** now and then and keep the file somewhere safe (Google Drive, iCloud).
To move to a new phone, install the app there and tap **Restore backup**.
